Run OQL through HTTP

Use execute mode only when the hardware is ready and the command is intentional.

BASE=http://192.168.188.122:8202
curl -s -X POST "$BASE/api/v1/oql/execute" \
  -H 'Content-Type: application/json' \
  -d '{"kind":"command","mode":"execute","oql":"SET \"pompa-1\" \"0\""}'

Run diagnostics

Manage verbs are the fastest way to verify firmware and hardware discovery.

BASE=http://192.168.188.122:8202
curl -s -X POST "$BASE/api/v1/oql/manage" \
  -H 'Content-Type: application/json' \
  -d '{"verb":"health","args":{"scan":"never"}}'

curl -s -X POST "$BASE/api/v1/oql/manage" \
  -H 'Content-Type: application/json' \
  -d '{"verb":"usb-list"}'
